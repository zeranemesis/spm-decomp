# Local game files

This directory is intentionally not versioned except for this README.

Provide files extracted from your own copy of Super Paper Mario:

- `main.dol`
- `relF.rel` (decompressed REL, not `relF.bin`)

Expected local paths:

```text
pc-port/game/main.dol
pc-port/game/relF.rel
```

Do not commit game binaries, disc images, textures, audio, or other Nintendo assets.
